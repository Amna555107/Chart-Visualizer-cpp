# Chart-Visualizer-cpp
An object-oriented C++ graphics project designed to visualize user-provided data through 10 different chart types. The project includes an interactive UI, data input system, and multiple visualization techniques such as bar charts, pie charts, line graphs, histograms, scatter plots, and stacked charts.
## Charts Implemented
- Bar Chart
- Pie Chart
- Line Chart
- Donut Chart
- Scatter Plot
- Area Chart
- Column Chart
- Histogram
- Stacked Bar Chart
- Multi-Line Chart

## Technologies Used
- C++
- graphics.h (BGI)
- Turbo C++ / WinBGIm
- Dev C++ with graphics header installed

## How to Run
1. Install a compiler that supports graphics.h (Turbo C++ or WinBGIm)  
2. Open the source file from `src/main.cpp`  
3. Compile and run the program  
4. Enter input values as prompted  
5. See the output charts
